- [ ] **ISS-004** `P2` `ContactMapper.refreshOrCreateActiveTime` SQL 无条件覆盖 `last_msg_id`，Consumer 消费延迟时旧 msgId 可覆盖新 msgId
  - 发现：ISS-003 review 阶段 reviewer E3，manager 2026-05-12 18:55 指示登记
  - 根因：`refreshOrCreateActiveTime` 的 ON DUPLICATE KEY UPDATE 用 `last_msg_id = VALUES(last_msg_id)`，无序保护；与 ISS-003 同事务写入产生竞态
  - 影响：并发或 Consumer 消费延迟时 `last_msg_id` 可能短暂回退，/chat/msg/page 漏返（自愈窗口短）
  - 修复方案：改为 `last_msg_id = IF(VALUES(last_msg_id) > last_msg_id, VALUES(last_msg_id), last_msg_id)`，与 `refreshOrCreateActive` 保持一致
  - 处置：ISS-003 合并后由 server-dev 提单独 PR
  - Owner：server-dev
